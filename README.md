# Data Science Environmental Monitoring

This repository contains coursework and analysis projects for environmental monitoring and data science.

## Assignment 1: Cluster hello

Bootstraps a synthetic GPP series and prints a 95% interval.

### Run

```bash
Rscript scripts/cluster_hello.R 200
```

## Assignment 2: FLUXNET Tower Data Analysis

Explores meteorological and carbon flux data from five FLUXNET flux tower sites. The analysis includes data quality, temporal patterns, carbon exchange, and energy balance.

### Files

- `reports/` — Jupyter notebook reports and HTML exports
- `scripts/` — Analysis code
- `jobs/` — Slurm job scripts
- `docs/` — Notes and templates

### Data

Data obtained through the `flux4student` course repository. Site-specific data citations and dataset acknowledgements are included in the report.
